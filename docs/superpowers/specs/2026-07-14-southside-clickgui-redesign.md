# Southside ClickGUI Redesign Spec

## 概述

将当前 ClickGUI 主面板从"左侧栏 + 右侧模块列表"重新设计为南方客户端(Southside b13)风格:左侧分组导航栏 + 右侧模块卡片网格 + 展开式设置面板,配以胶囊开关、带数值滑块、标签页等现代控件。ArrayList HUD、水印、Toast、悬浮球、登录界面等保持不变。

## 设计参考

南方客户端 Southside b13(基于 OneConfig/Polyfrost 架构),8 张参考截图已确认以下视觉特征:
- 单居中圆角面板 + 毛玻璃模糊背景
- 左侧分组导航(MOD CONFIG / PERSONALIZATION),带线性图标,蓝色高亮选中项
- 右侧模块卡片网格(2~3 列),每张卡片含模块名 + 描述 + 底部蓝色启用横条 + 展开箭头
- 展开后显示标签页 + 开关 + 滑块(带数值)+ 按键绑定
- 品牌蓝 #3B82F6 强调色,深黑背景 ~#14141a,卡片表面 ~#1e1e28

## 改动范围

**改:**
- `UIRenderer.java` — 核心渲染与触摸逻辑
- `ModuleItem.java` — 增加 description 字段、expanded 状态
- `Category.java` — 增加 icon 标识、section 分组

**不改:**
- ArrayList HUD、Watermark、Toast、悬浮球、LoginRenderer、BackgroundRenderer
- BlurPipeline、FrameBuffer、QuadBatch、TextRenderer、GlyphAtlas 等渲染基础设施
- Anim 动画系统
- 主题系统(8 套预设 + 自定义取色器)

## 详细设计

### 1. 整体面板布局

面板为单居中圆角矩形,尺寸约 `width=560dp, height=380dp`(横屏),分为三个垂直区域:

```
┌────────────────────────────────────────────────────────────┐
│ Header Bar (高 44dp)                                        │
│  SOAR b1   ← → [分类名]     [⌕ search...]           ×     │
├──────────┬─────────────────────────────────────────────────┤
│          │  Content Area                                    │
│ Sidebar  │  [分类名] Modules · N enabled                    │
│ (160dp)  │                                                  │
│          │  ┌────────┐ ┌────────┐ ┌────────┐             │
│ MAIN     │  │ Card 1 │ │ Card 2 │ │ Card 3 │             │
│  ⌂ Home  │  └────────┘ └────────┘ └────────┘             │
│  ▣ Module│  ┌────────┐ ┌──────────────────────┐            │
│          │  │ Card 4 │ │ Card 5 (expanded)    │            │
│ FEATURES │  │        │ │ [Gen][Behavior]      │            │
│  ♪ Music │  │        │ │ Toggle  [●━━] ON     │            │
│  ...     │  │        │ │ Slider  [━━●━] 1.0  │            │
│          │  └────────┘ └──────────────────────┘            │
│ SYSTEM   │                                                  │
│  ⚙ Setting│                                                 │
│          │                                                  │
├──────────┴─────────────────────────────────────────────────┤
│ Footer Bar (高 36dp)                                        │
│  [KeyBind: RSHIFT]                          [Close]         │
└────────────────────────────────────────────────────────────┘
```

### 2. 侧栏导航 (Sidebar)

**结构:** 保留现有 7 个分类,分为 3 组:

| 分组 | 分类 | 图标(Unicode) |
|------|------|---------------|
| MAIN | Home | ⌂ |
| MAIN | Module | ▣ |
| FEATURES | Cosmetics | 🎭 |
| FEATURES | Music | ♪ |
| FEATURES | Profile | ☺ |
| FEATURES | Screenshot | 📷 |
| SYSTEM | Setting | ⚙ |

**视觉:**
- 侧栏宽度 160dp,背景色 #16161e
- 分组标题:灰色小字(9px),大写字母,字间距 0.5px
- 分类项:高 28dp,图标(12px)+ 文字(12px),默认灰色 #9999aa
- 选中项:左侧 3px 蓝色竖条 + 半透明蓝色背景(rgba(59,130,246,0.15)) + 白色文字
- 选中高亮过渡:Anim 平滑插值(200ms)

**交互:**
- 点击切换分类,右侧内容区淡入淡出过渡

### 3. 模块卡片网格 (Card Grid)

**布局:**
- 内容区从侧栏右侧开始,padding 16dp
- 顶部显示:"[分类名] Modules · N modules · M enabled"(14px 白色 + 12px 灰色)
- 卡片网格:每行 2~3 列(根据面板宽度自适应),卡片间距 12dp
- 卡片尺寸:约 155dp × 70dp

**卡片视觉:**
- 背景:#1e1e28,圆角 8dp,边框 #2a2a38(1px)
- 模块名:白色 12px medium,左上角(距上 22dp,距左 12dp)
- 描述:灰色 9px,模块名下方(距上 36dp)
- 底部启用横条:3px 高,蓝色 #3B82F6,模块启用时显示,收起时贴底
- 展开箭头:▾(10px 灰色),右下角

**交互:**
- 点击卡片主体 → 切换模块开关(底部横条出现/消失,带动画)
- 点击 ▾ 箭头 → 展开/收起内联设置面板
- 按下时:卡片轻微缩放(0.97),松开回弹
- 卡片按下时边框变蓝色

### 4. 展开式设置面板

**展开动画:**
- 卡片高度从 70dp 插值到 70dp + 设置内容高度(约 120~180dp)
- 使用 EaseBackOut 缓动(回弹效果)
- 内容透明度从 0 渐变到 1(延迟 100ms 开始)
- 展开时卡片边框变蓝色(1.5px)

**面板内容(从上到下):**
1. 标签页栏(高 20dp)
   - 胶囊形按钮:General / Behavior / Animations(或根据模块动态生成)
   - 选中页:蓝色填充 #3B82F6 + 白色文字
   - 未选页:透明 + 灰色文字
   - 间距 4dp,圆角 10dp

2. 设置项列表(每项高 28dp,垂直间距 8dp):
   - 左侧:标签名(11px 浅色 #c0c0d0)
   - 右侧:控件

**控件类型:**

**胶囊开关 (Toggle Switch):**
- 轨道:28dp × 14dp,圆角 7dp(胶囊形)
- 开启:蓝色 #3B82F6 填充 + 白色圆钮(直径 10dp)居右
- 关闭:深灰 #333340 填充 + 白色圆钮居左
- 切换动画:圆钮水平位移插值(150ms)

**带数值滑块 (Slider with Value):**
- 轨道:120dp × 3dp,圆角 2dp,背景 #2a2a38
- 填充:蓝色 #3B82F6,从左到当前值
- 拖钮:白色圆形,直径 8dp,带轻微阴影
- 数值:拖钮右侧显示当前值(11px 灰色,如"1.0"、"4.2")
- 拖动时拖钮放大到 10dp

**按键绑定 (KeyBind Button):**
- 深色圆角矩形 #1e1e28,边框 #2a2a38,圆角 6dp
- 左侧显示控件用途(如"Click GUI KeyBind")
- 右侧显示当前绑定键名(如"RSHIFT")
- 点击后进入监听模式,显示"...",等待按键

### 5. 标题栏 (Header Bar)

**布局(高 44dp,背景 #1e1e28):**
- 左侧(距左 18dp):品牌名"SOAR b1"(13px 白色 medium,字间距 1px)
- 品牌名右侧:面包屑导航"← → [分类名]"(11px 灰色)
- 右侧:搜索框 + 关闭按钮

**搜索框:**
- 圆角胶囊 #232330,边框 #2a2a38,宽 120dp,高 24dp
- 左侧搜索图标 ⌕(11px 灰色)
- 占位文字:"search modules..."(10px 灰色)
- 输入时实时过滤当前分类的模块卡片

**关闭按钮:**
- × 符号(14px 灰色),点击关闭整个面板(等效于点击悬浮球)

### 6. 底部栏 (Footer Bar)

**布局(高 36dp):**
- 左侧:按键绑定控件(显示"Click GUI KeyBind"+ 当前键名)
- 右侧:Close 按钮(蓝色填充圆角矩形,60dp × 28dp,白色文字)

### 7. 配色方案

| 元素 | 颜色 |
|------|------|
| 面板背景 | #14141a (半透明 0.92 + 毛玻璃) |
| 标题栏/底栏背景 | #1e1e28 |
| 侧栏背景 | #16161e |
| 卡片背景 | #1e1e28 |
| 卡片边框 | #2a2a38 |
| 强调色(默认) | #3B82F6 (蓝) |
| 主文字 | #e8e8f0 |
| 次级文字 | #9999aa |
| 灰色图标 | #66667a |
| 分组标题 | #555560 |

**主题系统:** 保留现有 8 套预设 + 自定义取色器。强调色随主题变化,默认主题改为蓝色。

### 8. 动画规格

| 动画 | 时长 | 缓动 |
|------|------|------|
| 面板开合 | 400ms | EaseBackOut |
| 侧栏选中过渡 | 200ms | EaseOut |
| 卡片展开/收起 | 300ms | EaseBackOut |
| 卡片按下缩放 | 100ms | EaseOut |
| 开关切换 | 150ms | EaseOut |
| 标签页切换 | 200ms | 淡入淡出 |
| 内容区切换(分类) | 250ms | 淡入淡出 |

### 9. 触摸处理变更

**新增触摸区域:**
- 搜索框:点击激活输入,显示光标
- 卡片整体:点击切换开关(检测在卡片矩形内但不在 ▾ 箭头区域内)
- ▾ 箭头:点击展开/收起(检测在箭头 24×24dp 热区内)
- 标签页按钮:点击切换页面
- 开关控件:点击切换
- 滑块拖钮:按下后进入拖动模式,MOVE 时更新值
- 按键绑定按钮:点击进入监听模式,下一次按键事件设为新绑定

**保留:** 侧栏分类点击、面板外点击关闭、悬浮球拖动/点击

### 10. 数据模型变更

**ModuleItem.java 新增:**
```java
private String description;      // 模块简短描述
private boolean expanded;        // 设置面板是否展开
private int activeTab;            // 当前标签页索引
```

**Category.java 新增:**
```java
private String icon;              // Unicode 图标字符
private String section;           // 分组名: "MAIN" / "FEATURES" / "SYSTEM"
```

### 11. 不改动的部分(明确清单)

- ArrayList HUD(右侧已启用模块列表)— 完全不变
- Watermark(左上角水印)— 完全不变
- Toast 通知 — 完全不变
- 悬浮球 — 完全不变
- 登录/加载界面 — 完全不变
- 背景场景渲染(drawWorldScene)— 完全不变
- 主题配置弹窗(长按展开的设置面板)— 完全不变
- BlurPipeline / FrameBuffer / QuadBatch / TextRenderer / GlyphAtlas — 不改动
- Anim 动画系统 — 不改动,复用
